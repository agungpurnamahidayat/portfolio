# Agung Purnama Hidayat — Portfolio

Website portofolio statis untuk menampilkan profil, pengalaman, proyek, dan keahlian di bidang IT Support, networking, dan web development.

## Teknologi
- HTML5
- CSS3
- JavaScript

Tidak membutuhkan framework atau proses build.

## Menjalankan secara lokal
1. Ekstrak folder project.
2. Buka `index.html` menggunakan browser.

## Publikasi ke GitHub Pages
1. Buat repository bernama `agungpurnamahidayat.github.io`.
2. Upload seluruh isi folder ini ke branch `main`.
3. Buka Settings → Pages dan pastikan sumber publikasi dari branch `main` / root.
4. Tunggu proses deployment selesai.

Foto profil disimpan di `assets/profile.jpg`. Untuk menggantinya, gunakan nama file yang sama atau ubah jalur `src` pada elemen foto di `index.html`.

## Sebelum dipublikasikan
- Ganti tombol Email dengan alamat email profesional yang benar.
- Pastikan tautan repository proyek sudah sesuai.
- Tambahkan screenshot proyek yang benar jika tersedia.
- Periksa kembali semua deskripsi agar sesuai dengan kontribusi yang benar-benar dilakukan.

## Catatan
Website ini menggunakan informasi profil dan pengalaman yang tersedia. Beberapa tautan proyek diarahkan sementara ke profil GitHub dan perlu diperbarui ke repository spesifik bila sudah tersedia.
