Featured Project

Adaptive Telemetry Communication System for Drone Infrastructure Monitoring

Designed and implemented an adaptive telemetry communication system for drone-based infrastructure monitoring using ESP32 and LoRa SX1278 modules.

  • Developed an adaptive antenna switching mechanism based on received signal strength (RSSI) to improve telemetry communication reliability.
  • Implemented dual LoRa communication paths and evaluated communication performance using RSSI, SNR, delay, packet loss, and reliability metrics.
  • Developed a Python-based data logging system to collect and store telemetry data in CSV format for further analysis.
  • Analyzed telemetry data using Pandas and created comparative graphs to evaluate communication performance between antenna configurations and the adaptive switching approach.
  • Conducted communication testing at multiple distances to evaluate system performance and reliability.
